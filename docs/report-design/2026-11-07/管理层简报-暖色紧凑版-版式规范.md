# 管理层简报｜暖色紧凑版版式规范

版本日期：2026-11-07。基准文件：`管理层简报-暖色紧凑版.pdf`（4页）。本文件记录当前定稿样稿的视觉与内容组织规则，后续报告可沿用；未修改系统自动导出模板。页面内容保存在同目录的 `管理层简报-暖色紧凑版-页面内容.md`。

## 设计方向

采用B方案的暖色配色、A方案的管理层简报内容结构。正文直接陈述促销动向、商品价格和交易条件，减少留白，不设置单独封面。数量统计置于末尾附录。

## 纸张与网格

所有尺寸以PDF点（pt）为单位，1 pt = 1/72英寸。定位坐标以页面左上角为原点；实现时转换为PDF左下角坐标。

| 项目 | 参数 |
| --- | --- |
| 页面 | A4竖版，595.28 × 841.89 pt |
| 左右页边距 | 44 pt |
| 内容宽度 | 507 pt |
| 卡片内边距 | 左右14 pt，标题上方7-10 pt |
| 卡片间距 | 一般6-11 pt，按内容分组微调 |
| 正文起始位置 | y = 125 pt |

| 分页原则 | 一张卡片完整放在同一页；内容过多时增加页数，不强行压小字号 |

- 不增加“阅读提示”段落。

## 商品卡片结构与链接

卡片宽507 pt，x = 44。常规商品卡高114 pt；首页短卡高100 pt。字段顺序：

1. 左上角：品牌与活动/商品名称。
2. **右上角：可点击的“原文”链接**，与标题同行；来源链接不放在卡片底部。
3. 第二行：价格、折扣或活动状态，用主题色突出。
4. 第三部分：商品规格、活动范围等事实。
5. 随后：退款、运费、库存、活动期限等条件。
6. 底部：发布时间及作者，用小号灰色文字呈现。

常规卡片相对坐标：标题x = 58、y = 卡片顶部+7，标题可用宽度350 pt；单链接x = 501、y = 顶部+10；价格y = 顶部+28；事实段从顶部+49开始，后续段落按实际文本高度顺排，段间距2 pt。

同卡片包含两篇来源时，右上角用两个具体标签（如“灰黑款 / 姜黄款”），分别链接对应原文，避免一个链接代替两款商品。双链接区域x = 411，宽126 pt。链接与标题不得重叠。

当前附录补充卡片链接位于x = 450、y = 顶部+12的右上区域。来源索引页直接以笔记标题作为链接，不额外重复“原文”。

## 内容写法

- 用“商品特卖与价格”“门店活动”等具体标题，不用“逐条核实”“优先核实”“条件最完整”等工作流标签。
- 不向管理层分派核查任务；信息缺失时直接写“未说明活动地点”等事实。
- 摘要先写发生了什么、价格或促销机制是什么、哪些条件影响理解。
- 不把匹配数量、候选数量作为首页核心指标。
- 原文折扣与本报告判断要区分；个人购物体验不能写成品牌官方报价。
- 不把一种商品的折扣套用到另一种商品；保留币种、尺码、运费和退换限制。
- 相同信息不重复大段铺陈，不粘贴全文，不展示冗长网址。

## 交付检查

生成后逐页渲染检查文字无裁切、卡片无跨页、标题与右上链接不重叠；确认原文链接可点击。当前PDF共4页、37个链接入口（11个商品/活动入口及26条来源索引）。新增报告应随内容调整卡片高度和页数，以上绝对坐标仅用于复现本次样稿。
