# 本地监控报告界面

推荐一键启动（会自动打开浏览器）：

```bash
双击“启动监控面板.command”
```

启动器会在后台运行服务，即使关闭终端窗口也不会中断。若发现由启动器管理的旧服务没有响应，会先清理旧进程再启动，并将日志写入 `.runtime/dashboard.log`。

也可以只启动 API：

```bash
.venv/bin/python -m uvicorn api.main:app --host 127.0.0.1 --port 8080
```

打开 http://127.0.0.1:8080/reports 。该页面无需安装或构建前端依赖。

- 从 SQLite 小红书采集记录载入关键词和笔记，支持搜索、分页。
- 页面加载时自动初始化本地运行服务，并检查 Python、核心依赖、采集程序、数据目录和命令执行能力；“启动服务”按钮可在失败后重试或重新检查。页面提供“重启服务”和“关闭服务”，重启前会先停止当前抓取子进程。
- 不要直接双击 `api/static/reports.html`。如果误从 `file://` 打开，页面会改用本机 API 地址并提示正确启动方法；服务已经完全停止时，需要双击根目录的 `启动监控面板.command`，因为停止后的网页本身无法启动操作系统进程。
- 状态卡会扫描当前采集日志中的 HTTP 401/403/429、验证码和 IP 限制信号。没有命中时只表示当前日志没有明确证据，不能证明平台从未实施限制。
- 页面分为“经销商”“品牌”和“REV 头盔”三个工作区；采集记录、统计、报告设置和历史报告分别展示。
- 本地服务检查卡片左侧集中显示精简运行状态和精确到秒的数据版本时间，检查、重启和抓取按钮整齐排列在右侧。抓取任务按经销商设置中的当前关键词更新本地数据，并显示关键词级百分比进度；抓取期间统一锁定其他按钮，完成后自动刷新记录和时间戳。
- “主要品牌专项监控”可独立执行 Bogner、Atomic/Aomic、Salomon、HEAD、Burton、ThirtyTwo、卢西诺/Rossignol 的小红书采集。任务先补采已知 Burton 官方活动，再逐个搜索品牌关键词；每个关键词最多读取 20 条，不采集评论或媒体。
- “REV 头盔问题监控”使用固定专项关键词跟踪负面评价、投诉、开裂破损、松动固定、撞击保护和佩戴视野问题，并显示关键词级抓取进度。
- REV 记录与经销商、品牌记录隔离；风险报告按型号、问题类型和关注等级汇总，高关注线索优先展示。关注等级只用于安排复核顺序，不能代替产品认证、召回公告、事故材料或实物检测。
- 编辑关键词、选择发布时间范围后点击“即时生成报告”。留空关键词表示全部。
- 关键词设置保存在当前浏览器；经销商报告保存到 `data/reports/`，品牌报告保存到 `data/reports/brand/`，REV 风险报告保存到 `data/reports/rev/`，重启后仍可分别查询。
- 历史列表包含原有 Markdown 报告，支持正文搜索、查看、图标删除和下载；经销商与品牌列表均每页显示 5 份。
- 报告详情支持下载 Markdown 或排版后的 PDF；PDF 包含重点摘要、价格突出、正文层级、原文链接和页码，并以分割线区分相邻促销线索。
- 重点摘要同时显示线索发布者和原文链接；正文不重复显示摘要。每条促销简报默认最多展示约 20 行，内容较长时可点击“查看详情”展开。
- 新报告按促销词提取候选线索，过滤带有明确境外地点、货币或现场活动信号的信息；候选线索按冷山、傲天、黑桃/SPADERS、三夫/攀山鼠、其他排序，同级按发布时间倒序。
- 报告附原文和全部匹配笔记；不自动判断活动真实性或有效期，不调用模型，也不触发新采集。
- 历史报告排序时间使用文件修改时间；页面时间均以 Asia/Shanghai 显示。

验证：`.venv/bin/python -m pytest tests/test_reports_api.py -q`
