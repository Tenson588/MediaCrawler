# 本地监控报告界面

推荐一键启动（会自动打开浏览器）：

```bash
.venv/bin/python start_dashboard.py
```

也可以只启动 API：

```bash
.venv/bin/python -m uvicorn api.main:app --host 127.0.0.1 --port 8080
```

打开 http://127.0.0.1:8080/reports 。该页面无需安装或构建前端依赖。

- 从 SQLite 小红书采集记录载入关键词和笔记，支持搜索、分页。
- 页面加载时自动初始化本地运行服务，并检查 Python、核心依赖、采集程序、数据目录和命令执行能力；“启动服务”按钮可在失败后重试或重新检查。
- 页面分为“经销商”和“品牌”两个工作区；采集记录、统计、报告设置和历史报告分别展示。
- “主要品牌专项监控”可独立执行 Bogner、Atomic/Aomic、Salomon、HEAD、Burton、ThirtyTwo、卢西诺/Rossignol 的小红书采集。任务先补采已知 Burton 官方活动，再逐个搜索品牌关键词；每个关键词最多读取 20 条，不采集评论或媒体。
- 编辑关键词、选择发布时间范围后点击“即时生成报告”。留空关键词表示全部。
- 关键词设置保存在当前浏览器；经销商报告保存到 `data/reports/`，品牌报告保存到 `data/reports/brand/`，重启后仍可分别查询。
- 历史列表包含原有 Markdown 报告，支持正文搜索、查看和下载。
- 报告详情支持下载 Markdown 或排版后的 PDF；PDF 包含重点摘要、价格突出、正文层级、原文链接和页码。
- 新报告按促销词提取候选线索，并附原文和全部匹配笔记；不自动判断活动真实性或有效期，不调用模型，也不触发新采集。
- 历史报告排序时间使用文件修改时间；页面时间均以 Asia/Shanghai 显示。

验证：`.venv/bin/python -m pytest tests/test_reports_api.py -q`
