# 版本说明：小红书雪具促销监控试运行版

发布日期：2026-10-19
适用分支：`main`

## 版本目标

本版本用于验证 MediaCrawler 在 macOS 本地环境中持续采集小红书雪具促销信息的可行性，重点解决浏览器启动、登录态复用、页面加载稳定性和结果时效性问题。

## 已完成改进

### 1. 小红书搜索按最新发布时间排序

将小红书搜索排序方式由热度优先调整为时间倒序：

```python
SORT_TYPE = "time_descending"
```

这使促销、闪购、清仓和限时活动更容易在发布后及时进入采集结果，适合日常优惠监控。

### 2. 标准 Playwright 模式使用本机 Chrome

默认关闭 CDP 模式，并配置 macOS Chrome 路径：

```python
ENABLE_CDP_MODE = False
CUSTOM_BROWSER_PATH = "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
```

标准模式启动浏览器时会把 `CUSTOM_BROWSER_PATH` 传给 Playwright。开启 `SAVE_LOGIN_STATE` 后，登录信息保存在本地、已被 Git 忽略的浏览器数据目录中，后续运行可以复用登录状态。

### 3. 提高小红书首页加载稳定性

首页导航改为等待 DOM 加载完成，并设置 60 秒超时：

```python
await self.context_page.goto(
    self.index_url,
    wait_until="domcontentloaded",
    timeout=60_000,
)
```

该调整避免等待页面全部网络请求结束，降低小红书持续请求或加载较慢时出现导航超时的概率。

## 本地验证

已在 macOS、本机 Chrome、Python 3.11 虚拟环境下完成一次登录和两轮采集验证：

- 二维码登录成功，后续运行正确识别已有登录态，无需再次扫码。
- 关闭评论采集和媒体下载，仅保存帖子信息到 SQLite。
- 商家词试跑包含冷山、傲天、SPADERS/黑桃等 8 个关键词。
- 本轮触达 127 条去重笔记，其中 83 条发布于最近 7 天。
- 成功发现冷山双十一、SPADERS 双11开板季及其他品牌促销线索。
- Python 编译检查和 Git diff 格式检查通过。

运行时产生的以下内容不会提交到 Git：

- `browser_data/`：浏览器登录状态和 Cookie。
- `database/*.db`：本地 SQLite 数据库。
- `data/`：采集结果和本地分析报告。
- `.venv/`：Python 虚拟环境。

## 当前使用方式

可以通过命令行传入逗号分隔的监控词：

```bash
.venv/bin/python main.py \
  --platform xhs \
  --type search \
  --lt qrcode \
  --keywords '冷山雪具,冷山商城,傲天雪具,SPADERS黑桃,ACE CLUB 雪具,雪具店 特卖' \
  --crawler_max_notes_count 20 \
  --get_comment false \
  --get_media false \
  --save_data_option sqlite \
  --max_concurrency_num 1
```

请遵守项目许可证、目标平台条款及合理采集频率要求。

## 已知限制

1. 小红书搜索接口每页固定返回约 20 条内容；当前实现会把小于 20 的采集上限自动提高到 20，并读取该页全部候选帖详情。
2. `KEYWORDS` 仍是一个平铺的逗号分隔字符串，尚不支持经销商、品牌、集散地、全国特卖的分组和轮换调度。
3. 每条笔记只保存一个 `source_keyword`。同一笔记命中多个查询词时，当前数据结构不能完整保留所有匹配关系。
4. 采集层没有按发布时间截断；最近 48 小时或最近 7 天的范围目前需要在报告阶段过滤。
5. Chrome 路径采用 macOS 默认安装位置；其他操作系统或自定义安装位置需要修改 `CUSTOM_BROWSER_PATH`。
