# 版本说明：监控任务拆分与访问限制保护

发布日期：2026-10-22
适用分支：`main`

## 本次目标

完善本地雪具情报工作台的服务控制和专项监控能力，将经销商、品牌与 REV 头盔任务完全拆分，并降低连续请求触发平台访问限制的概率。

## 主要变更

### 1. 三类独立监控

- 经销商、品牌、REV 头盔分别提供采集按钮、任务状态、进度和独立报告。
- 经销商任务不会同时启动品牌或 REV 任务，减少无关访问。
- REV 专项按型号、结构与撞击保护、佩戴固定、视野舒适、质量投诉等维度整理问题线索。
- REV 报告按高、中、一般关注排序，并明确用户内容属于待核实线索。

### 2. 本地服务控制

- 本地服务状态折叠为单行展示，以颜色直接区分运行正常和异常。
- 增加启动、重启和关闭服务能力；重启或关闭前会停止活动采集进程。
- 增加 Finder 可双击的 `启动监控面板.command`，负责启动本地 API 并打开报告页面。
- 支持从本地 `file://` 页面连接 `127.0.0.1:8080`，并显示正确的服务入口。

### 3. 验证码与访问限制处理

- 检测 401、403、429、461、471、验证码和账号安全限制信号，并在界面显示诊断信息。
- 提供可见浏览器入口用于人工处理登录或验证码，并在结束后释放浏览器配置目录。
- 小红书 461/471 验证码响应不再自动重试，避免一次限制连续形成多条访问请求。
- 首次发现访问限制后立即停止本轮剩余笔记和关键词。
- 请求间隔调整为 5–10 秒随机等待，减少固定节奏和短时间连续访问。
- 启用项目专用的持久化 CDP Chrome；无需每次确认连接已有浏览器，首次登录后复用登录状态。

### 4. 报告与历史记录

- 历史报告每页显示 5 条，支持搜索、翻页和图标删除。
- 报告摘要补充发布者、原文链接、价格条件和活动排除条件。
- 简报正文限制显示高度，超出内容可展开查看详情。
- PDF 打印原文 URL，并在促销线索之间增加分割线。
- 报告元数据统一放在末尾备注区，减少正文重复。

## 使用提示

- 三类监控应按实际需要分别执行，避免在短时间内连续运行全部任务。
- 专用 CDP Chrome 首次运行可能需要登录；登录数据保存在本地 `browser_data/`，不会提交到 Git。
- 访问限制由平台决定，本次调整用于减少触发概率并在限制发生后及时停止，不能保证平台永远不要求验证。
